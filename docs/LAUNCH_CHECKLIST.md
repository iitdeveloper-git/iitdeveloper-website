# Launch checklist

- [ ] Confirm founder name/profile and approved public biography.
- [ ] Verify client/project descriptions and add approved screenshots.
- [ ] Confirm public email, phone/location policy, and social profile URLs.
- [ ] Configure the real booking URL.
- [ ] Configure production database and apply migrations.
- [ ] Configure Resend and test both email directions.
- [ ] Confirm privacy/terms text with appropriate legal review.
- [ ] Set analytics and consent behavior.
- [ ] Add Google and Bing verification values.
- [ ] Run type-check, lint, production build, and dependency audit.
- [ ] Test keyboard navigation and form errors.
- [ ] Test mobile navigation and representative viewport sizes.
- [ ] Validate JSON-LD and canonical tags.
- [ ] Crawl the deployed preview for broken internal links.
- [ ] Confirm preview deployments are noindex.
- [ ] Confirm apex/www permanent redirect.
- [ ] Submit the sitemap after DNS cutover.
- [ ] Record the previous stable deployment for rollback.
